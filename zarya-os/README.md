# Операционная система «Zarya»

## Описание
Zarya — это современная операционная система, сочетающая:
- **Плавность и визуальную эстетику macOS** (анимации, прозрачность, тени)
- **Функциональность и кастомизацию Windows** (рабочий стол, панель задач, оконный менеджер)
- **Мобильную отзывчивость Android** (жесты, адаптивные интерфейсы)
- **Свободу и модульность Linux** (открытая архитектура, пакетный менеджер)

## Архитектура

```
zarya-os/
├── boot/              # Загрузчик (UEFI/Multiboot2)
├── kernel/            # Ядро на Rust
│   └── src/
│       ├── memory/    # Управление памятью
│       ├── task/      # Планировщик задач
│       ├── ipc/       # Межпроцессное взаимодействие
│       ├── drivers/   # Драйверы устройств
│       ├── fs/        # Файловая система ZFS
│       ├── syscall/   # Системные вызовы
│       ├── net/       # Сетевой стек
│       └── sync/      # Примитивы синхронизации
├── servers/           # Системные сервисы
│   ├── zds/           # Display Server
│   ├── input/         # Сервис ввода
│   ├── fs/            # Файловый сервер
│   └── network/       # Сетевой сервер
├── apps/              # Приложения
│   ├── zarya-desktop  # Рабочий стол
│   ├── zarya-files    # Файловый менеджер
│   ├── zarya-text     # Текстовый редактор
│   ├── zarya-terminal # Терминал
│   ├── zarya-settings # Настройки
│   └── zarya-login    # Экран входа
├── lib/               # Библиотеки
│   ├── libzarya       # Системная библиотека
│   └── zui            # GUI тулкит
└── docs/              # Документация
```

## Сборка

```bash
# Сборка образа системы
./build.sh

# Запуск в QEMU
make run
```

## Требования
- Rust nightly toolchain
- QEMU для эмуляции
- UEFI или BIOS совместимая система
